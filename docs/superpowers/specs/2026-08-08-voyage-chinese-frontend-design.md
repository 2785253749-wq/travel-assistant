# Voyage 中文旅行助手前端改造设计

**日期：** 2026-08-08
**状态：** 待用户审阅
**前置条件：** 当前安全审查、发布前验证与代码发布闭环完成后再实施。

## 目标

将现有旅行助手升级为中文优先的 Voyage 风格网页体验，同时保留已验证的认证、聊天、确认规划、行程保存/复制/分享、额度与异常兜底流程。

第一版使用本地占位图和本地展示数据，必须可离线运行；不引入地图 Key、第三方地图服务或真实社区发帖。

## 范围与分期

### 第 1 期：探索页地图试点

- 顶部中文导航：探索、我的行程、社区；仅保留 `Voyage AI` 等品牌英文。
- 左侧为地图与推荐区，右侧固定为 AI 助手会话区。
- 地图使用本地 SVG/GeoJSON 与本地数据，初始显示中国地图。
- 试点覆盖福建、云南：点击省份平滑缩放到省级视图；显示热门城市、景点大头针与景点卡片。
- 点击厦门、福州、大理、丽江等试点城市后，继续平滑缩放到城市级视图并显示该市热门景点。
- 点击省份、城市或景点会自动在右侧 AI 会话中新增一条对应的中文推荐消息，并显示相关快捷追问。
- 推荐卡片使用本地占位图，景点、城市和快捷问题都来自本地演示数据。
- 地图层级切换采用 transform/opacity 动画，支持键盘操作与“返回全国/返回省份”。

### 第 2 期：我的行程页

- 左栏显示即将开始、历史行程及最近计划。
- 中栏按天渲染现有已保存行程的时间线、交通/住宿/活动卡片与未规划提示。
- 右栏展示离线天气占位、预算、覆盖城市、同行人数、确认单和分享入口。
- 读取现有行程接口，继续遵守服务端可信 itinerary 边界；页面不提交原始 itinerary。

### 第 3 期：社区页（本地静态）

- 使用中文分类筛选：全部、摄影控、美食地图、独自旅行、城市漫步、自然风光、亲子游。
- 本地静态游记瀑布流，卡片包含占位图、目的地、标题、作者、点赞和评论展示值。
- 筛选仅操作本地状态；点赞、评论和发布按钮为非持久化演示状态，不创建社区后端接口。

### 第 4 期：全国扩展

- 仅在福建/云南试点通过交互、性能与测试验收后实施。
- 复用相同 `省 -> 城市 -> 景点` 数据格式逐步增加全国边界和景点数据；不重写地图组件。
- 真实图片和真实内容源也在此后作为独立数据替换任务处理。

## 视觉与交互规范

- 浅灰页面背景、白色卡片、深蓝主色、轻阴影、圆角 20–28px。
- 桌面端采用双栏：左侧内容约 60%，右侧 AI 助手约 40%；小屏降为内容与助手的可切换纵向区域。
- 卡片统一图片比例、中文字号层级和空状态；禁止把后端原始 JSON 渲染到聊天区。
- AI 自动推荐必须复用当前安全聊天响应结构；当没有可靠数据时显示现有拒答/降级文案，不伪造景点事实。

## 前端边界

- 现有后端接口和安全流程保持兼容；视觉层通过页面状态适配，不能绕过 `collect -> confirm` 的确认边界。
- 地图演示数据、占位图及社区静态数据与真实行程数据分层，避免把演示内容写入用户行程。
- 不在浏览器新增任何密钥或敏感配置。

## 验收与测试

- 探索页：省级和市级缩放、返回路径、针点选择、AI 自动消息、键盘可达性、窄屏布局。
- 行程页：现有 trip 的加载、空行程、服务端复制/删除后界面同步。
- 社区页：分类筛选、卡片布局和本地交互状态。
- 回归：现有前端聊天确认、认证、分享、XSS 与 URL 防护测试继续通过。
- 离线：断网时占位图、试点地图和社区演示数据仍可展示；真实 provider 相关请求继续走既有降级提示。

## 不在本轮范围

- 全国所有省市景点的完整数据。
- 真实社区用户、发帖、评论、点赞持久化。
- 真实天气、地图瓦片、在线图片或任何付费 API。
- 改变当前规划、权限、额度与公开仓库安全策略。
