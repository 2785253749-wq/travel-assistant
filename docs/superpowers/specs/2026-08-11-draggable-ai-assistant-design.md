# 可拖动 AI 助手设计

## 目标

将探索页的 Voyage AI 助手调整为非阻塞、可拖动的悬浮工具窗。未主动点击时，助手必须保持关闭，不得因地图、省份、城市或景点选择而自行弹出。

## 交互

- 初始状态：只显示右下角“打开 AI 助手”按钮，助手面板隐藏。
- 开关：点击按钮打开；面板打开时，再次点击同一按钮关闭。按钮的可见文字与 `aria-expanded` 同步变化。
- 拖动：仅顶部标题栏是拖动手柄。使用 Pointer Events 支持鼠标与触屏；拖动可停在当前浏览器视口任意位置，但面板四周至少保留 12px，不能被拖出屏幕。
- 关闭：不再展示独立叉号；Esc 仍关闭面板并让焦点回到开关按钮。
- 地图：选择省、市、景点只更新本地推荐消息和景点卡，绝不调用 `/api/chat`、绝不强制打开面板或移动焦点。
- 刷新：不保存位置，刷新后回到右下角默认位置。

## 响应式与可访问性

- 宽屏维持紧凑浮窗；窄屏仍为较宽的浮层，但可通过顶部标题栏拖动。
- 拖动开始时只阻止标题栏的文本选择，不阻止聊天内容的滚动或输入。
- 标题栏提供明确的可拖动提示，并保持按钮、输入框、Esc 与键盘焦点的既有语义。
- `prefers-reduced-motion` 下不引入额外位移动画。

## 实现边界

- 只修改 `index.html`、`app/static/app.js`、`app/static/styles.css` 和前端测试。
- 不修改 AI 调用、行程生成、鉴权、配额、数据库、地图 SDK 配置或密钥处理。
- 不新增依赖；不得将拖拽位置写入 localStorage。

## 验收与测试

1. 默认隐藏，地图选择后仍隐藏；点击开关才打开。
2. 打开后再次点击开关关闭，Esc 也关闭并恢复开关焦点。
3. Pointer 拖拽标题栏更新面板位置，且会被约束在视口 12px 边距内。
4. 聊天消息区、输入框与发送行为仍可用，且本地地图推荐没有 `/api/chat` 请求。
5. 既有完整前端回归及相关 Python 前端资产测试通过。
