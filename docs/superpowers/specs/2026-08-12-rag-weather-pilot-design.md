# RAG 旅行知识库与天气试点设计

日期：2026-08-12
状态：已由用户确认，等待规格审阅后进入实施计划。

## 目标

为旅行助手增加一个小范围、可核验的知识问答能力，并增加独立的高德实时天气能力。

试点范围仅包含福建、云南和厦门，内容覆盖景点、交通、餐饮、季节和避坑提示。系统必须给出资料来源；没有足够资料时必须拒答，不得编造。天气不是 RAG 资料的一部分。

## 范围与非范围

本期包含：

- 项目内维护的精选中文旅行资料。
- Supabase pgvector 向量检索和 Jina 中文 Embedding。
- 回答中的中文来源标签。
- 高德天气的问答入口、地图城市选择入口和行程天气区块。
- 80 条离线评测和工程化配置、日志、迁移、导入工具。

本期不包含：

- 用户上传文件或自动抓取网页。
- 全国知识库。
- 超过高德预报窗口的实时天气。
- 向浏览器暴露任何服务端密钥。

## 方案选择

采用“Supabase pgvector + 云端中文 Embedding”方案。

资料和向量保存在现有 Supabase 项目。Jina 仅负责把资料段落和查询转为向量；聊天模型仍只负责依据检索证据组织中文回答。该方案比关键词检索更能处理同义问法，也比在 Render 免费实例中加载中文模型更稳定。

## 知识资料与导入

资料作为版本化文件随仓库保存。每条资料必须包含：标题、地区、主题、正文、来源标签和最后核对日期。

导入工具将资料按短段落切分，生成 Embedding 后写入知识段落表。导入必须可重复运行：相同资料版本不能重复创建段落或向量。

数据库迁移启用 pgvector，并保存资料元数据、正文、向量、版本和导入时间。匿名用户不得直接写入或读取原始知识库表；仅后端 service role 可访问。

## 问答与引用规则

1. 旅行知识问题触发检索，后端取得相关度最高的 3 至 4 个段落。
2. 相关度不足、无资料、Embedding 服务不可用或检索异常时，回答固定的中文拒答说明：资料库没有足够依据，无法可靠回答。
3. 聊天模型只能使用检索到的证据回答。每个事实性段落末尾显示简短中文来源标签，例如“来源：厦门出行资料”。
4. 不允许模型凭一般知识补充未检索到的交通、价格、开放时间或天气事实。

## 独立天气服务

天气通过高德 Web 服务 API 查询，不写入知识库，也不使用地图 JS Key。

- `AMAP_WEB_SERVICE_KEY` 只在 Render 后端配置。
- 通过城市 adcode 查询实况或预报；响应中保留高德 `reporttime` 作为发布时间。
- 用户直接询问天气时，返回中文天气、温度、风力和发布时间。
- 用户选择地图城市时，显示一个小天气卡片；失败时显示“天气暂不可用”。
- 使用短缓存、超时和独立的每日调用上限，避免重复调用和意外费用。

高德天气预报只覆盖当天、第二天、第三天。行程结果按目的地和日期合并天气：在预报窗口内显示高德预报和发布时间；超出窗口时，若知识库有该地区的季节建议，则显示并明确标注“非实时天气”；没有资料则不显示天气建议。天气服务失败不得阻止行程生成。

## 行程与前端展示

天气由后端合并进入行程结果，不能交由聊天模型虚构。行程页面在每日安排附近展示天气信息或季节建议，清楚标明资料类型和更新时间。

地图城市卡片显示天气摘要，不发起聊天请求。现有可拖动助手、行程保存、分享、鉴权和配额行为保持不变。

## 配置、日志与费用控制

新增的服务端配置至少包括：

- `JINA_API_KEY`
- `AMAP_WEB_SERVICE_KEY`
- Embedding 每日调用上限
- 天气每日调用上限
- 天气缓存时长和请求超时

Key 绝不进入前端运行时配置、日志、测试快照或 Git。日志只记录检索命中数量、相似度、拒答原因、天气调用状态和耗时；不记录完整私密对话内容。

## 评测与验收

新增 80 条离线题：

- 45 条可由试点资料回答的问题，要求答案与中文来源标签匹配。
- 15 条资料库外问题，要求明确拒答。
- 10 条引用完整性和不可编造边界题。
- 10 条天气、三日预报边界、季节建议和天气失败兜底题。

另需覆盖：迁移与 RLS、资料幂等导入、Embedding 失败、检索阈值、天气缓存/超时/上限、行程天气合并、前端天气卡片和既有回归。

## 外部准备

在实施和部署前，用户需申请 Jina Embedding Key 与高德 Web 服务 API Key，并仅将它们填入 Render 环境变量。高德天气接口按 adcode 查询当前或未来天气，预报为当天、第二天、第三天；以接口返回的 `reporttime` 为准。官方文档：<https://developer.amap.com/api/webservice/guide/api/weatherinfo>。
