# 高德地图 Voyage 探索页试点设计

## 目标

将当前过渡版页面替换为接近 Voyage 参考图的探索页：紧凑顶部导航、地图主视觉、热门目的地卡片和右下角悬浮 AI 助手。首版只覆盖福建、云南及厦门、福州、大理、丽江，验证地图缩放和景点选择流程后再扩展全国。

## 页面与布局

- 桌面端使用浅灰蓝页面背景和白色圆角内容区。
- 顶部显示 `Voyage` 品牌、探索/我的行程/社区导航、目的地搜索入口和账户入口；探索页为当前页。
- 探索主区左侧是地图，右侧是当前省份或城市的热门目的地卡片。
- 悬浮 AI 助手固定在右下角，不占用主内容列；窄屏时改为底部抽屉。
- 我的行程和社区仅保留导航入口。本次不伪造完整的行程工作台或社区数据。

## 地图行为

1. 初始渲染高德中国地图，并为福建、云南提供可见入口。
2. 选择福建或云南时，地图使用高德的平滑定位与缩放能力，显示对应城市：厦门/福州或大理/丽江。
3. 选择城市时，地图继续平滑放大，并显示该城市三个本地定义的热门景点大头针。
4. 选择景点时，打开本地景点信息卡，包含名称、简短介绍和离线占位图。
5. 省、市和景点选择均会向悬浮助手写入一条本地中文推荐；此操作不请求 `/api/chat`，不消耗 DeepSeek 额度。

## 高德配置与安全边界

- 生产环境通过 Render 环境变量 `AMAP_JS_KEY` 提供高德 JavaScript API Key；仓库、测试夹具、文档和日志中不得写入实际 Key。
- Key 仅用于浏览器地图加载；在高德控制台限制为生产域名 `https://travel-assistant-2cbd.onrender.com` 及本地开发地址 `http://127.0.0.1`。
- 高德脚本依赖或初始化失败时，显示中文降级提示并自动使用本地 SVG 地图；福建/云南、省、市和景点选择流程仍可执行。
- 不增加后端地理编码、地点搜索或路线规划调用；因此本次不需要 Web 服务 Key。
- 不改变既有 `collect -> confirm` 规划流程、认证、额度、行程保存接口或 DeepSeek 调用边界。

## 数据与模块边界

- `explore-data`：冻结的福建、云南、四个城市和每城三个景点的中文名称、坐标、简介与占位图引用。
- `map-explorer`：只负责加载高德或离线地图、维护国家/省/市层级、放置标记并抛出结构化选择事件。
- `explore-page`：负责当前层级标题、热门卡片和将选择事件交给助手推荐。
- `assistant`：仅追加可信的本地推荐消息；只有用户主动提交文本时才沿用现有聊天 API。

## 响应式与无障碍

- 宽度不大于 900px 时，地图、推荐卡片和内容区改为单列；助手为最大高度 78vh 的底部抽屉。
- 地图入口、城市和景点具备可键盘操作的等效控件与可读名称。
- `prefers-reduced-motion: reduce` 下关闭地图外的自定义缩放/弹出动画；高德自身无法控制的动画不作为验收失败条件。

## 验收与测试

- 前端测试覆盖：高德成功路径的福建/云南选择、城市缩放、景点针点、本地推荐不发起 fetch、地图失败自动降级、悬浮助手与导航可用。
- 手工验收覆盖：Render 环境填入 Key 后，中国地图可加载；去除 Key 后离线 SVG 仍可完成试点流程。
- 回归运行 Node 前端测试与 Python 全量测试；不得修改评测题库、基线或阈值。

## 非目标

- 本次不覆盖全国省市、不使用真实景点图片、不实现在线地点检索、路线规划或支付功能。
- 本次不把高德或用户行程内容写入浏览器以外的持久化存储。
